# 代码逻辑改动记录

> 2026-07-28，记一下这版代码相对师兄原方案的改动和实车调试踩的坑。
> 新工程在 `swarm_lab_jiang_v1/`，实验数据在 `report_v1/results/codeoutputs/`。

## 背景：师兄原方案

- **静止 leader**：部分车给定零速度钉死不动，follower 做 bearing 跟随；
- **差速运动学**：世界系速度指令 → 目标航向 + 标量速度 → 航向 PID + 速度 PID → 左右轮差速分配（麦轮车当差速车开）。

## 改动 1：运动学 —— 差速 → 麦轮全向

**原因**：bearing 控制律的理论模型是全向单积分器（指令速度直接是位置变化率），
但差速执行要先转向、后直行，速度方向始终滞后指令方向，相位滞后注入编队回路
就是之前收敛曲线震荡的主要来源；而且麦轮的全向能力完全被浪费了。

**做法**（`swarm/algorithms/mecanum.py`）：世界系速度经 `R(-yaw)` 转到车体系，
走 X 型麦轮逆运动学直接分四轮，不再需要"先转向"：

```
FL = vx_b - vy_b - ω·L    FR = vx_b + vy_b + ω·L
RL = vx_b + vy_b - ω·L    RR = vx_b - vy_b + ω·L
```

另加了一个低增益航向保持 P 控制（锁住解锁时刻的初始 yaw），防止平移时车头乱转
影响动捕 marker 观测。旧差速模式保留（`execution.mode="diff"`），可做 A/B 对比。

## 改动 2：编队逻辑 —— 静止 leader → 全员运动

**原因**：静止 leader 把编队的平移/旋转/尺度全锁在 leader 基线上，摆放方向必须和
期望 bearing 严格一致，否则 follower 的可达构型会退化（实际踩过，见下面 87° 事故）。

**做法**（`BearingControlConfig.agent_mode`，默认 `all_bearing`）：所有车都跑
bearing 控制律，没有静止锚点。无向边对两端作用对称（净力为零，质心理想不动），
形状必然收敛，但整体平移/旋转/尺度自由（bearing-only 固有自由度，可接受）。
另保留 `leader_velocity`（旧行为）和 `leader_bias`（leader 带速度偏置，以后做编队机动）。

顺带把控制律本身也修正到理论形式：

- 旧：逐边误差求均值 + 向量 PI，**无投影矩阵**；
- 新：`u_i = k_p · Σ P_ij(g_ij − g*_ij)`，P = I − g·gᵀ（去掉沿视线分量，不跟尺度打架），
  求和不求均值，tanh 平滑饱和 + 死区，bearing 默认 2D（屏蔽动捕 z 高度噪声）。

## 实车调试踩的坑（物理世界部分）

1. **87° 事故**：一次实验中两个 leader 沿 +y 摆，但期望 bearing 是 +x（差 87°），
   静止 leader 没法自我修正，follower 的目标构型退化成 8 mm 宽的狭缝，永远不可能收敛。
   → 新增 **preflight 起飞前校验**（`swarm/application/preflight.py`）：leader 基线与期望
   bearing 夹角 >20° 直接拒绝起飞、最小车距 0.2 m、逐边初始误差表 + 回车确认。
   （全员运动模式下编队可自由旋转，这项校验自动跳过。）

2. **跑一段就原地卡死**：误差变小 → 指令变小 → 低于电机静摩擦死区，车有指令但不动，
   残留 8~15° 误差。查数据发现实际速度只有指令的 0.4~0.6 倍（轮速标定 0.5 m/s 偏大，
   实测约 0.3）。→ 标定改回 0.3 + 新增**死区补偿** `wheel_command_min_effective`
   （非零指令抬到阈值以上，零保持零），阈值用 `tools/check_wheels.py --ramp` 实测。

3. **个别车运动方向不对**（前进指令横着走、转向反号）：轮序/极性/麦轮滚子方向问题。
   → 写了 `tools/check_wheels.py` 单车开环校验（直行/平移/旋转/逐轮点动），
   编队实验前先过一遍，硬件问题不带上编队。

4. 工程细节：UDP 改持久 socket（原来每条指令新建）；动捕 twist 缺失时用位置差分 + EMA
   估速度；实验结束自动把轨迹存成运行目录下 `trajectory.png`（之前 Ctrl-C 会把绘图
   进程一起杀掉，存不存上看运气，已修）。

各运行目录里的 `trajectory.png`。单元测试 84 项全绿（含全员运动模式的端到端收敛回归：
理想积分器下 30 s 内 RMS < 5°）。

## 遗留 / 下一步

- 全员运动模式下编队的**尺度和旋转不受控**，长时间会缓慢漂移；必要时加尺度修正项
  （stimulus 仿真里已有 `scaleCorrection` 可参考）或切回 leader 模式。
- 死区阈值随电量变化明显，实验前充满电；`wheel_command_min_effective` 目前全编队统一，
  后续可按车分配。
- 六车（bearing_six）配置已就绪，未实测。
