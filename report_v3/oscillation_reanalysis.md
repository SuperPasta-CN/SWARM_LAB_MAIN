# v3 巡航振荡：修正版归因（9-07 实车 A/B 实验之后）

> 本文取代并修正 `oscillation_analysis.md` 中的部分结论。前文的机理框架
> （两个极限环、反馈延迟的相位角色）仍然成立，但**"min_eff 量化是根因"**
> 的论断被 9-07 实车对照实验证伪。真正正确的结论是：
> **振荡器 = "PI 速度环 + 低速死区"的组合体；量化只是它的一种外衣。**

## 1. 9-07 实车对照实验结果（`report_v3/runs_ab/`，指标由
`analysis/scripts/oscillation_metrics.py` 计算）

| 组 | 换向率（次/s/轮） | 速度波纹中位 | yaw 摆动中位 | 稳态边误差 |
| --- | --- | --- | --- | --- |
| 基线（lift） | 1.7–1.9 | 49–51% | 3.7–10.0° | 0.0317 m |
| **pwm** | **0.3–0.6** | **46%** | 1.9–3.1° | **0.0171 m** |
| affine | 2.4（同基线） | 49–61% | 8.2–12.7°（更差） | 0.0423 m（变差） |
| hdb（航向死区） | 2.5 | 66–68% | **2.4–2.8°** | 0.0306 m |
| ema（α=0.5） | 2.5–2.8 | 59% | 2.1–3.1° | 0.0261 m |
| all（affine+hdb+ema） | 3.0–3.1 | 55–62% | 2.8–4.4° | 0.0411 m（变差） |

## 2. 三个决定性观察与前论断的证伪

**观察 1（affine 组）：去量化后振荡同频同幅。**
affine 把"小指令钉死 ±35"改成了连续映射（数据里指令确实不再钉在 ±35，
抬升占比 81%→2%），但轮指令在 −62…+85 区间以 ~2.4 次/s 换向、
速度与基线同频（~1.4 Hz）同幅甚至更大——**振荡器不是量化本身，
而是环路本身**。前文"量化决定振荡是否存在"的论断不成立。

**观察 2（pwm 组）：换向率塌缩 4–8 倍，队形误差还更好了。**
PWM 没有消灭环路的振荡倾向，而是**绕过了它**：巡航 0.10 m/s 低于
"最低可持续速度"，连续推力物理上不存在（见 §3），PWM 用时间平均
提供正确的平均推力，环路不再被迫用极限环自我平均。
附带收益：亚阈值修正成为可能，稳态边误差 0.0317→0.0171 m。

**观察 3（hdb/ema 只有边际作用）。**
航向死区确实压住了 yaw 摆动（10.0°→2.4–2.8°，与其定位一致）；
EMA 提速几乎无变化——**0.12 s 的反馈延迟不是必要条件**，
前文把它的权重估高了。

## 3. 修正后的完整机理

低速死区的真实形态（9-07 数据实测）：它不是"低于 35 不动、
过了 35 才有推力的温和阈值"，而是——

```
|cmd| < ~25      : 完全不动（静摩擦锁死）
 cmd ≈ 35        : 最低可持续速度 ~0.10–0.18 m/s（逐车/逐轮/逐向不同）
```

**巡航目标 0.10 m/s 正好落在"连续不可达区"**：没有任何连续指令能
持续产出这个速度。于是闭环只能两选一：

- lift/affine：环路用极限环自我平均（±35 bang-bang 或更糟的连续抖动），
  频率由"积分充放电时间 × 车体惯性"设定（实测 ~0.5–0.7 s 半周期，
  与积分限幅 0.10 的充放时间一致）；
- **pwm：由执行器在更高载波（5 Hz）上做时间平均**，
  载波远高于环路自然频率，车体惯性把它滤平——环路看到的是"正确的
  平均对象"，于是安静下来。

一句话：不是"环路振荡 + 死区放大"，而是**"死区把连续控制变成了
不存在解的问题，PWM 把问题还原成有解的形式"**。

## 4. 仿真验证（`analysis/scripts/sim_limit_cycle.py`）

一阶车体 + 滞滑死区（释放 35 / 保持 15、v(35)=0.175）+ 滞后估计器 +
与实车一致的 PI（kp=0.6, ki=1.2, 限幅 0.10/0.15）：

| 仿真条件 | 结果 | 与实车一致性 |
| --- | --- | --- |
| ideal（无死区） | 波纹 0%，换向 0 | 证明死区是振荡的**必要条件** ✓ |
| lift | 与 affine 同频的 bang-bang | ✓ |
| affine | 同频、幅度不降 | ✓（实车同结论） |
| **pwm** | 换向归零，均值精确 | ✓（实车同结论） |
| kp/ki 扫参（0.2–1.2） | lift/affine 极限环在所有增益下存在 | 调 PI 不是解 ✓ |
| tau_est 扫参（0.05–0.20 s） | 影响微小 | 与 ema 组实车边际无效一致 ✓ |
| pwm 周期扫参 | 4–10 拍良好，20 拍过慢 | 现场可复验 |

**仿真的局限（诚实声明）**：单标量对称车体模型的波纹幅度
（4–6%）系统性低于实车（46–77%）——实车的逐轮标定不对称、
滞滑强度与方向差异、估计器噪声都更大；仿真用于判别"哪种机制
存在/不存在"，不用于预测绝对幅度。

## 5. 修正后的结论与行动项

1. **采用 pwm 为默认死区策略**（`deadzone_mode="pwm"`，实车+仿真双证）。
   lift/affine 保留作对照模块，文档标记为"不推荐"。
2. **航向死区保留**（hdb：yaw 摆动 10.0°→2.4–2.8°，定向有效）；
   EMA α 改回 0.3（无效改动，不必保留）。
3. **精度上限提醒**：PWM 的平均速度 = duty × v(35)，而 v(35) 逐车不同
   （0.10–0.18 m/s）——9-07 pwm 组平均速度 0.095 vs 目标 0.10（−5%）
   即由此产生。下一步用 `check_wheels --ramp` 按车实测 v(35) 并可
   按车配置 `execution_override`。
4. 巡航速度若提到 **≥0.18–0.2 m/s**（连续可达区之上），理论上连
   PWM 都不需要；可作为对照实验组验证边界。
5. 建议的下一组实验：`v3_two_pwm` + `heading_deadband_rad=0.035`
   组合全开组（即新的 `v3_two_all` 语义改为 pwm），确认组合效果。
