# Bearing 编队控制交互式演示

基于 Web 的多智能体（Multi-Agent）**Bearing 编队控制**交互式可视化系统。实时展示智能体从随机初始分布收敛到预设 Bearing 编队构型的完整动态过程，基于 **Bearing Rigidity Theory**（轴承刚性理论）与矩阵加权一致性（Matrix-Weighted Consensus）实现。

## 运行方式

```bash
# 安装依赖（已安装可跳过）
npm install

# 开发模式
npm run dev        # 默认 http://localhost:5173

# 生产构建 + 预览
npm run build
npm run preview    # 默认 http://localhost:4173
```

要求：Node.js 20+，Chrome / Edge / Firefox 最新版。

## 核心算法公式

### 1. Bearing（方位）定义 —— 对应论文 Eq. (2)

对每条无向通信边 (i, j)，单位方位向量：

```
g_ij = (p_j − p_i) / ‖p_j − p_i‖
```

期望 bearing g*_ij 由目标编队构型以同样方式计算。

### 2. 矩阵加权控制律 —— 投影矩阵 P = I − ggᵀ

```
u_i = Σ_{j∈N_i} P_ij · (g_ij − g*_ij),   P_ij = I − g_ij·g_ijᵀ
```

投影矩阵的几何意义：控制量**只作用于垂直于视线方向的子空间**，沿视线方向的分量属于 null(P)。这是 bearing 控制「尺度与平移不可控」的根本原因，也是与普通标量加权一致性的本质区别（权重是矩阵而非标量）。

### 3. 尺度修正项（可选，默认开）

```
f_scale = k_d · (d_ij − d*_ij) · g_ij        （沿视线方向，属于 null(P) 子空间）
```

补充距离误差信息，使编队尺寸收敛到「目标边长」滑块设定值。

### 4. 质心对齐项（可选，默认开）

```
u_i += k_c · (centroid_target − centroid_current)   （对所有 i 相同）
```

共同模态项：不改变任何相对 bearing，仅消除编队整体的平移自由度，使收敛位置与目标虚影重合。

### 5. 执行器饱和 —— sat(u, v_max)

| 类型 | 公式 |
|---|---|
| 硬截断 Hard | `v = u·min(1, v_max/‖u‖)` |
| 平滑饱和 tanh | `v = tanh(‖u‖/v_max)·v_max·û` |
| 符号函数 Sign | `v_i = v_max·tanh(k·u_i) ≈ v_max·sign(u_i)` |

饱和中的智能体会显示红色闪烁边框；可选「角速度限制」模拟真实车辆转向能力（ω ≤ ω_max）。

### 6. 事件触发机制（相对+绝对混合阈值）

```
触发条件：‖u(t) − u(t_k)‖ ≥ σ·‖u(t)‖ + 0.01
```

两次触发之间控制量**零阶保持**。注意其理论后果：只能保证**实用稳定**（误差收敛到阈值邻域而非 0），但控制更新次数可减少 90% 以上（触发次数在「实时数据」页统计）。

### 7. 动力学与积分

一阶积分器模型：`ṗ_i = v_i`，显式欧拉积分 `p_i(t+h) = p_i(t) + h·v_i`，步长 h = 0.02s。
收敛判据：全局 bearing 误差 `‖e_b‖ = sqrt(Σ_边 ‖g_ij − g*_ij‖²) < ε`。

## 功能一览

- **主画布**：深色科技风 Canvas 渲染；智能体颜色随局部误差红→绿渐变；运动轨迹；拓扑连线（粗细随距离）；实线/虚线箭头分别表示实际与期望 bearing；目标编队虚影与包围盒标注
- **交互编辑**：拖拽智能体初始位置（支持回溯后分叉）；拖拽/点击编辑目标编队点；点击两个智能体自定义连边
- **控制面板**：3 种控制律、3 种饱和函数、Kp/Ki 增益、v_max/ω_max、事件触发阈值、尺度修正、质心对齐、收敛阈值
- **拓扑与编队**：N=3–20；全连接/环形/链式/自定义拓扑（含邻接矩阵可视化、连通性检查警告）；随机/圆形/直线/聚簇初始分布
- **13 种目标编队**：
  - 基础：正方形、正 N 边形、链式/直线
  - 几何：矩形、五角星、V 形（雁阵）、网格、同心圆环、箭头、心形（参数曲线）
  - 创意：**文字编队**（离屏 Canvas 渲染字形，从笔画像素中采样 N 个目标点，支持 ≤6 字符自定义，如 SJTU/CMU）、**手绘编队**（画布上直接绘制任意形状，沿笔画弧长均匀采样）
  - 手动：自定义（逐点点击）
  - 几何/创意编队基于「归一化形状 → 弧长等距采样」框架生成，任意 N 均可适配
  - ⚠️ 不规则点集（文字/手绘/网格等）在环形/链式稀疏拓扑下约束不足（bearing 刚性需 2n−3 条独立约束），选择这些编队时系统自动切换为全连接拓扑
- **动态演示**：播放/暂停/步进/重置、时间轴回溯、0.1–5x 倍速、收敛进度条
- **数据面板**：全局误差曲线（线性/对数）、逐智能体状态表（位置/速度/局部误差/触发次数/饱和状态）
- **导出**：画布 PNG 截图；全部参数 JSON 导出/导入复现

## 实现说明

- 渲染：HTML5 Canvas 2D（性能优先）；误差曲线为轻量 SVG（降采样至 ≤400 点）
- 状态：Zustand；历史快照上限 6000 条，超出后自动隔帧降采样
- N ≤ 20 时计算量为 O(N²) 边遍历（≤190 条），主线程 60fps 无压力，故未引入 Web Worker
